## Principios de UI para juegos

- Claridad sobre estilo
- Feedback inmediato
- Consistencia visual
- Accesibilidad

## Elementos comunes

- Menús y pantallas de carga
- HUD (health, score, minimapa)
- Inventarios y diálogos
- Configuraciones y opciones

## Implementación

- Godot: Control nodes (Container, Button, Label)
- Unity: Canvas y UI Toolkit
- Animaciones de UI para feedback
