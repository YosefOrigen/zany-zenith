- **Nodo TileMapLayer** — Nodo para mapas 2D basados en tiles. Un **TileMapLayer** utiliza un *TileSet* que contiene una lista de tiles que se utilizan para crear mapas basados en cuadrículas. A diferencia del nodo *TileMap*, que está obsoleto, **TileMapLayer** tiene solo una capa de tiles. Puedes usar varios **TileMapLayer** para lograr el mismo resultado que un nodo *TileMap*.
<br/>
- **Recurso TileSet** — Define los tiles en sí. Contiene fuentes (atlas, colección de escenas, etc.), capas de física, capas de navegación, capas de datos personalizados y conjuntos de terreno.
