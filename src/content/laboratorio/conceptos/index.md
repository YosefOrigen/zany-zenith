## Game Loop

El corazón de todo videojuego. Procesa entrada, actualiza el estado del juego y renderiza en cada frame.

## ECS (Entity Component System)

Arquitectura que separa datos (componentes) de comportamiento (sistemas) para entidades.

## Spatial Partitioning

Técnica para optimizar detección de colisiones dividiendo el espacio en regiones más pequeñas.

## State Machines

Máquinas de estado para manejar comportamientos (idle, caminar, saltar, atacar) de forma ordenada.
